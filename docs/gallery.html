Gallery

Each chart below is drawn from the code under it, with real data defined at the top of examples/catalog.php:

Variable Data
$mpg, $mtcars, $economics, $faithful the bundled datasets: ggplot2’s mpg and economics, and R’s mtcars and faithful, from Datasets
$gapminder gapminder: life expectancy, population, and GDP per capita of 142 countries, 1952 to 2007
$fit, $reduced linear models of mtcars fuel economy, fitted in PHP
$schools posterior draws of the eight schools model, sampled with CmdStanPHP
$hwyMean, $hwySd the mean and standard deviation of highway mpg in mpg

With ggplot2-style functions

ggplot2-style functions compose with apply(), or with the pipe operator on PHP 8.5.

Vega-Lite specification

    geom_point(alpha: 0.4),
    geom_smooth(span: 0.5),
    labs(
        title: 'Loess smooth',
        x: 'Displacement (L)',
        y: 'Highway mpg',
    ),
    theme_minimal(),
);

Means with error bars

Precomputed means with normal-approximation 95% intervals.

Vega-Lite specification
Plot::of(array_map(
    function ($class) use ($mpg) {
        $rows = array_filter(
            $mpg,
            fn ($r) => $r['class'] === $class,
        );
        $values = array_column($rows, 'hwy');
        $n = count($values);
        $mean = array_sum($values) / $n;
        $squares = array_map(
            fn ($v) => ($v - $mean) ** 2,
            $values,
        );
        $se = sqrt(array_sum($squares) / ($n - 1) / $n);

        return [
            'class' => $class,
            'mean' => $mean,
            'lower' => $mean - 1.96 * $se,
            'upper' => $mean + 1.96 * $se,
        ];
    },
    array_values(array_unique(array_column($mpg, 'class'))),
))
    ->aes(x: 'class', y: 'mean', ymin: 'lower', ymax: 'upper')
    ->errorbar(width: 8)
    ->point(size: 50)
    ->labs(x: null, y: 'Mean highway mpg (95% CI)');

Functions

curve() draws a PHP function, here a normal density with the mean and standard deviation of highway mpg.

Vega-Lite specification
Plot::of($mpg)
    ->aes(x: 'hwy')
    ->histogram(binwidth: 2, density: true, fill: '#DDDDDD')
    ->curve(
        fn (float $x) => exp(-0.5 * (($x - $hwyMean) / $hwySd) ** 2)
            / ($hwySd * sqrt(2 * M_PI)),
        10,
        46,
        aes: aes(x: 'hwy', y: 'density'),
        color: '#D62728',
        linewidth: 2,
    )
    ->labs(x: 'Highway mpg', y: 'Density');
