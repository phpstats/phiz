Geoms

Each geom adds a layer. Every geom method accepts these common arguments:

  • aes:, mappings for this layer only
  • data:, data for this layer only
  • inheritAes: false, to ignore the plot’s mappings
  • filter:, a Vega expression string or a selection predicate such as ['param' => 'brush']
  • fixed styles by their ggplot2 names (alpha, color, fill, size, linewidth, linetype, shape) or as any Vega-Lite mark property (strokeWidth: 2, cursor: 'pointer')

As in ggplot2, color is the outline of bars, areas, and tiles, and fill is their interior. For points, lines, and text, color is the main color. linetype accepts ggplot2’s names (dashed, dotted, dotdash, longdash, twodash), hex dash strings such as '44', or a dash array.

Distributions

histogram() bins a continuous variable. bins: sets the maximum number of bins, and Vega-Lite chooses rounded boundaries. binwidth: sets the width exactly and boundary: anchors the bins.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::faithful())
    ->aes(x: 'waiting')
    ->histogram(binwidth: 2, fill: '#4C78A8')
    ->labs(x: 'Minutes between eruptions');

density() draws a kernel density estimate per group with Vega-Lite’s density transform. bw: sets the bandwidth. adjust: multiplies a bandwidth computed with R’s bw.nrd0 rule. Mapping fill draws filled areas; otherwise the densities are lines.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'hwy', fill: 'drv')
    ->density(alpha: 0.4, adjust: 1.5)
    ->labs(x: 'Highway mpg', fill: 'Drive');

boxplot() draws Tukey boxplots with whiskers at coef: interquartile ranges. Points layered on top show the raw data.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'drv', y: 'hwy')
    ->boxplot(outliers: false, fill: '#DDDDDD', color: '#333333')
    ->jitter(width: 0.25, alpha: 0.35)
    ->labs(x: 'Drive', y: 'Highway mpg');

violin() draws a kernel density of y for each level of a discrete x. Every violin has the same maximum width, set by width: as a share of the band, and violins layer with boxplots and points on the same axis. bw: and adjust: work as in density(), and position: 'dodge' places groups side by side.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'drv', y: 'hwy', fill: 'drv')
    ->violin(alpha: 0.6, adjust: 1.2)
    ->jitter(width: 0.08, alpha: 0.3)
    ->theme('gray')
    ->labs(x: 'Drive', y: 'Highway mpg', fill: 'Drive');

ecdf(), freqpoly(), qq(), qqLine(), and rug() complete the set.

Amounts

bar() counts rows per level of x when y is unmapped, and col() draws the y values. position: is stack (the default), dodge, fill (stacked to 100%), or identity.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'class', fill: 'drv')
    ->bar(position: 'dodge')
    ->labs(x: null, y: 'Cars', fill: 'Drive');

col() with xmin and xmax mapped draws precomputed bins. tile() and rect() draw heatmaps and rectangles, and bin2d() counts points in a two-dimensional grid.

use Phiz\Datasets;
use Phiz\Plot;

use function Phiz\factor;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'class', y: factor('cyl'), fill: 'mean(hwy)')
    ->tile(color: 'white')
    ->scaleFill(scheme: 'viridis')
    ->labs(x: null, y: 'Cylinders', fill: 'Mean hwy');

Lines and areas

line() connects points in order of x. path() connects them in data order, and step() draws stairsteps. area() fills from zero and stacks by fill, and ribbon() fills between ymin and ymax.

use Phiz\Datasets;
use Phiz\Plot;

$recent = array_slice(Datasets::economics(), -180);

$plot = Plot::of($recent)
    ->aes(x: 'date', y: 'uempmed')
    ->area(fill: '#9ECAE1', alpha: 0.5)
    ->line(color: '#08519C')
    ->labs(x: null, y: 'Median weeks unemployed');

Intervals

errorbar(), linerange(), and pointrange() draw intervals from ymin to ymax. With xmin and xmax they are horizontal. position: 'dodge' places groups side by side, which the coefficient plots use to compare models.

use Phiz\Plot;

$estimates = [
    ['site' => 'North', 'mean' => 4.1, 'lower' => 3.2, 'upper' => 5.0],
    ['site' => 'East', 'mean' => 5.3, 'lower' => 4.6, 'upper' => 6.1],
    ['site' => 'South', 'mean' => 3.4, 'lower' => 2.1, 'upper' => 4.6],
    ['site' => 'West', 'mean' => 4.8, 'lower' => 4.2, 'upper' => 5.5],
];

$plot = Plot::of($estimates)
    ->aes(x: 'site', y: 'mean', ymin: 'lower', ymax: 'upper')
    ->errorbar(width: 10)
    ->point(size: 60)
    ->hline(4.5, linetype: 'dashed', color: '#888888')
    ->labs(x: null, y: 'Mean score (95% CI)');

Reference lines

hline() and vline() draw rules at fixed values, at every value of a list, or at a mapped yintercept or xintercept field. abline() draws y = intercept + slope * x across the range of the data.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mpg())
    ->aes(x: 'cty', y: 'hwy')
    ->point(alpha: 0.4)
    ->abline(0, 1, linetype: 'dashed')
    ->hline(30, color: '#D62728')
    ->vline(20, color: '#1F77B4')
    ->labs(x: 'City mpg', y: 'Highway mpg');

Text

text() and label() draw the label aesthetic. hjust, vjust, and angle follow ggplot2: angle turns text counterclockwise. nudgeX and nudgeY move labels in pixels.

use Phiz\Datasets;
use Phiz\Plot;

$fast = array_values(array_filter(Datasets::mtcars(), fn ($car) => $car['hp'] > 180));

$plot = Plot::of($fast)
    ->aes(x: 'hp', y: 'qsec', label: 'model')
    ->point()
    ->text(hjust: 0, nudgeX: 6, size: 10)
    ->labs(x: 'Horsepower', y: 'Quarter-mile time (s)');

Fitted curves

smooth() fits a curve per group. With method: 'lm', 'quad', or 'poly' and inline data, phiz fits the model in PHP by least squares and draws a pointwise confidence band for the mean at level:, as ggplot2’s geom_smooth() does. These bands match R’s predict(fit, interval = "confidence"). se: false and the other methods (loess, log, exp, pow) use Vega-Lite’s regression and loess transforms in the browser, without a band. span: sets the loess bandwidth.

use Phiz\Datasets;
use Phiz\Plot;

$plot = Plot::of(Datasets::mtcars())
    ->aes(x: 'hp', y: 'mpg')
    ->point()
    ->smooth(method: 'poly', order: 2, level: 0.9)
    ->labs(x: 'Horsepower', y: 'mpg');

curve() draws a PHP function over a range, as ggplot2’s geom_function() does.

use Phiz\Datasets;
use Phiz\Plot;

$eruptions = array_column(Datasets::faithful(), 'eruptions');
$mean = array_sum($eruptions) / count($eruptions);
$sd = sqrt(array_sum(array_map(fn ($x) => ($x - $mean) ** 2, $eruptions)) / (count($eruptions) - 1));
$normal = fn (float $x) => exp(-0.5 * (($x - $mean) / $sd) ** 2) / ($sd * sqrt(2 * M_PI));

$plot = Plot::of(Datasets::faithful())
    ->aes(x: 'eruptions')
    ->histogram(binwidth: 0.2, density: true, fill: '#DDDDDD')
    ->curve($normal, 1.5, 5.5, aes: ['x' => 'eruptions', 'y' => 'density'], color: '#D62728')
    ->labs(x: 'Eruption length (min)', subtitle: 'A single normal curve fits this bimodal distribution poorly');

Raw layers

layer() adds any Vega-Lite layer as given, and geom() adds a geom by name with explicit parameter and style arrays.
